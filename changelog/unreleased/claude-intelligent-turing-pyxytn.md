title: Guides for browser agents, the MCP server and the HTTP API
---
Three new guides cover what AI assistants and scripts can do with TopoStack. [Use a browser agent in the studio](/guides/browser-agents) lists the tools an agent in your browser tab can use to change and generate your design, and what stays in your hands. The [MCP server reference](/guides/mcp-server) and the [project request and HTTP API reference](/guides/agent-api) describe every tool, request field, error and limit for people building on them. Long commands in guides now scroll inside their box instead of widening the page.
